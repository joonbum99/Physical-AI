Data Preprocessing Pipeline

데이터 전처리 5단계 핵심 파이프라인

불량 프레임 차단부터 로봇 3D 좌표 최적화까지 단계적으로 처리합니다.

STAGE 01

Geometry & Quality Gate

렌즈 왜곡을 보정하고 흐림, 과노출, 가림, Depth 결손 프레임을 재촬영 대상으로 분류합니다. 선정 근거: 입력 품질이 낮은 프레임을 그대로 사용하면 오검출뿐 아니라 잘못된 3D 좌표가 생성되므로 AI 추론 전에 차단합니다.

Output: 정상 RGB-D
STAGE 02

Sensor Noise Clean-Up

Bilateral Filter로 철분진과 스패터 노이즈를 억제하면서 볼트와 용접 비드의 경계는 보존합니다. 선정 근거: Gaussian Filter보다 경계 보존성이 높아 작은 볼트 윤곽과 얇은 용접선을 흐리지 않으면서 표면 노이즈를 완화할 수 있습니다.

Output: Clean RGB-D
STAGE 03

Photometric Normalization

CLAHE를 적용해 저조도와 국부 그림자를 완화하고 작업 대상과 금속 배경의 대비를 높입니다. 선정 근거: 전체 밝기를 일괄 증가시키면 금속 반사부가 포화되므로, 국부 영역별 대비를 조절하는 CLAHE가 기관실 음영 환경에 적합합니다.

Output: 대비 정규화 영상
STAGE 04

Feature & ROI Enhancement

AprilTag와 CAD 예상좌표를 활용해 작업 대상 ROI를 추출하고 주변 배관과 구조물의 영향을 줄입니다. 선정 근거: 전체 프레임에는 유사한 볼트·배관이 많으므로 예상 작업영역으로 탐색 범위를 제한해 오검출과 연산량을 동시에 줄입니다.

Output: 작업 대상 ROI
STAGE 05

Coordinate Optimization

Hand-Eye Calibration을 적용하여 카메라 좌표를 Robot Base 좌표로 변환하고 제작 편차를 보정합니다. 선정 근거: 검출 박스의 이미지 좌표만으로 로봇을 이동시킬 수 없으므로 Depth와 외부 파라미터를 결합해 실제 Robot Base 좌표로 변환합니다.

Output: 보정 로봇 좌표

YOLO26n Fine-Tuning

선박 작업구역 AI 파인튜닝

사전학습된 YOLO26n을 기반으로 볼트 체결부·용접부·케이블 접속부를 학습합니다.

CLASS 0

볼트 체결부

로봇이 볼팅 작업을 수행해야 하는 체결 위치를 바운딩박스로 검출합니다.

CLASS 1

용접부

배관과 철판 연결부 등 로봇 용접이 필요한 작업구역을 검출합니다.

CLASS 2

케이블 접속부

커넥터와 단자 등 케이블 체결 작업이 필요한 접속 위치를 검출합니다.

Parameters & Rationale

핵심 학습 파라미터와 선정 근거

model=yolo26n.ptNano

산업용 PC의 실시간 추론 부담을 줄이고, 소규모 산업 데이터에서 대형 모델보다 과적합 위험을 낮추기 위해 선정했습니다.

imgsz=1280고해상도

선박 전체 영상에서 작은 볼트·커넥터가 차지하는 픽셀이 적으므로 640보다 형상과 얇은 용접 경계를 더 많이 보존합니다.

batch=8VRAM 균형

1280 입력의 메모리 사용량을 고려해 Colab급 GPU에서 OOM을 줄이면서 Gradient 안정성을 확보하는 절충값입니다.

epochs=300 · patience=20충분한 적응 + 조기종료

COCO와 금속 선박 영상의 도메인 차이를 학습할 상한은 확보하되, 20 Epoch 동안 개선이 없으면 과적합과 불필요한 연산을 차단합니다.

optimizer=AdamW · lr0=0.001안정적 미세조정

소규모 전이학습의 빠른 수렴과 가중치 감쇠를 활용하며, 낮은 학습률로 기존 윤곽 특징이 급격히 무너지는 것을 방지합니다.

scale=0.5 · mosaic=0.5중간 강도 증강

작업거리와 배경 다양성을 학습하되, mosaic=1.0에서 발생할 수 있는 비현실적인 선박 장면과 작은 객체 소실을 피합니다.

cache=disk · amp=True자원 최적화

고해상도 데이터를 RAM 대신 디스크에 캐시해 메모리 부족을 줄이고, 혼합 정밀도로 VRAM과 학습시간을 절감합니다.

multi_scale=False입력 일관성

운영 카메라 해상도가 고정될 예정이므로 배치마다 입력 크기를 바꾸지 않고 작은 객체의 픽셀 조건과 VRAM 사용량을 일정하게 유지합니다.

Training Process

2단계 파인튜닝 과정

1

사전 오류 점검

전체 학습 전 fraction=0.10으로 데이터 경로, 클래스 번호, 라벨 위치와 GPU 메모리를 점검합니다.

2

Stage 1 · 검출 Head 우선 학습

초기 30 Epoch 동안 freeze=10을 적용하여 Backbone 특징을 보호하고 3개 작업 클래스의 분류 기준을 먼저 안정화합니다.

3

Stage 2 · 전체 레이어 미세조정

이후 270 Epoch 동안 freeze=None으로 전환하여 금속 표면, 용접 비드, 케이블 단자의 세부 질감을 학습합니다.

4

검증 및 최종 모델 선정

전체 mAP와 함께 클래스별 AP·Precision·Recall을 확인하고, 마지막 가중치가 아닌 최고 검증 성능의 best.pt를 적용합니다.

작은 작업부 검출

imgsz=1280으로 작은 볼트와 케이블 접속부의 픽셀 정보를 보존합니다.

안정적인 전이학습

단계적 동결 해제로 사전학습 특징의 급격한 손상을 방지합니다.

현장 일반화 성능

scale=0.5와 mosaic=0.5로 작업거리와 배경 변화에 대응합니다.

경량 실시간 운영

Nano 모델과 AMP를 사용해 학습 자원과 추론 부담을 줄입니다.

최종 적용 기준

오류 분석에서는 conf=0.10, 현장 운영 초기값은 conf=0.50을 적용합니다. 클래스별 Recall이 낮은 경우 전체 mAP가 높더라도 실제 로봇 작업 모델로 사용하지 않습니다.

OUTPUT · best.pt

YOLO26 Model Validation

IoU · mAP 기반 학습검증

전체 mAP 한 개만으로 모델을 판단하지 않고, 예측 박스의 위치 정밀도와 클래스별 오검출·미검출을 분리해 검증합니다. 로봇이 검출 중심점을 실제 작업 좌표에 활용하므로 일반 객체 인식보다 높은 IoU 구간의 성능을 반드시 함께 확인합니다.

DATA SPLIT

영상 단위 데이터 분리

Train 70%, Validation 20%, Test 10%를 권장합니다. 동일 영상의 인접 프레임이 서로 다른 세트에 섞이면 배경과 대상이 거의 같아 성능이 과대평가되므로 반드시 원본 영상 단위로 분리합니다.

선정 근거 · 실제 신규 블록과 촬영조건에 대한 일반화 성능을 검증하기 위함
LOCALIZATION

IoU 0.50 · 0.75 이중 검증

IoU 0.50은 작업 대상을 전반적으로 찾는 능력을, IoU 0.75는 볼트 머리·용접 경계·케이블 단자에 박스가 정밀하게 맞는지를 평가합니다.

선정 근거 · 검출 성공과 로봇 좌표용 위치 정밀도는 서로 다른 성능이므로 분리 평가
ACCURACY

mAP50 · mAP50-95 병행

mAP50은 기본 검출 능력, mAP50-95는 IoU 0.50~0.95를 평균해 정밀한 위치 일치까지 반영합니다. 세 클래스의 AP도 별도로 확인합니다.

선정 근거 · 쉬운 IoU 조건만 사용할 때 발생하는 성능 과대평가 방지

초기 성능 판정 기준

전체 mAP50≥ 0.85
전체 mAP50-95≥ 0.60
클래스별 AP50≥ 0.80
Precision≥ 0.85
Recall≥ 0.80

위 값은 초기 개발 목표이며 실제 현장 적용값은 Test 데이터와 로봇 작업 실패 비용을 기준으로 재조정합니다. 특히 클래스별 Recall이 낮으면 전체 mAP가 높아도 적용하지 않습니다.

YOLO26 검증 코드

from ultralytics import YOLO

model = YOLO(
    "/content/runs/ship_work_stage2/weights/best.pt"
)

metrics = model.val(
    data=data_yaml,
    split="val",
    imgsz=1280,
    batch=8,
    conf=0.001,
    iou=0.70,
    plots=True,
    save_json=True,
    project="/content/runs",
    name="ship_work_validation"
)

print("mAP50:", metrics.box.map50)
print("mAP50-95:", metrics.box.map)

conf=0.001은 PR Curve와 AP 계산에서 낮은 신뢰도 후보까지 포함하기 위한 검증값입니다. iou=0.70은 중복 박스를 제거하는 NMS 기준이며, mAP의 IoU 평가 기준과는 다른 파라미터입니다.

PR Curve
