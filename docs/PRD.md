# AI 비전 기반 6축 로봇 좌표 인식·자동보정 시스템 PRD

[나만의 피지컬 AI 제작]  
• 제품 : AI 비전 기반 6축 로봇 좌표 인식·자동보정 시스템
• 인식하는 것 : 부품의 X·Y 위치, 회전각도(θ), 형상 및 기준 좌표와의 편차
• Action
  - 카메라 이미지에서 부품의 중심 좌표와 회전각도 검출
  - 기준 좌표 대비 X·Y·θ 편차 계산 후 로봇 작업 좌표 자동보정
  - 보정 후 부품 위치 재촬영 및 허용오차 충족 여부 재검증
  - 보정 한계 초과 또는 반복 보정 실패 시 로봇 정지 및 위치 이상 알람

[PRD]
① 문제정의 : 부품 안착 위치와 각도 편차로 인해 로봇의 용접·조립 작업 위치가 어긋나며, 작업자가 수동으로 좌표를 재티칭하는 과정에서 생산 지연과 품질 편차 발생
② 작업자 시나리오 : 부품 투입 → 비전 촬영 → 위치·각도 편차 계산 → 로봇 좌표 자동보정 → 보정 위치 재검증 → 용접·조립 수행 → 작업 결과 저장
③ KPI : 위치 검출 정확도 99% 이상 / 보정 후 위치오차 ±2mm 이내 / 좌표 보정 성공률 95% 이상 / 로봇 작업 실패율 10% 이하
④ 기술스택 : 산업용 카메라, 조명, OpenCV, YOLO, 이미지↔좌표변환, TCP/IP 통신
⑤ 범위/비범위
  - 범위 : 평면 부품의 X·Y·θ 편차 검출, 로봇 좌표 자동보정, 로봇팔 피드백 제어 동작 연계, 재검증
  - 비범위 : 복잡한 3D 형상 인식, 로봇 충돌회피 경로 자동생성

⑥ ROI
<Input> 카메라·조명 500만원 + 산업용 PC 300만원 + 로봇 통신·제어장치 300만원 + SW 개발비 1,200만원 = 초기 투자비 2,300만원
<Output> 수동 재티칭 공수 절감 1,200만원/년 + 위치 불량·재작업 감소 2,000만원/년 + 생산중단시간 감소 800만원/년 = 연간 절감액 4,000만원

▶ 투자 회수기간: 2,300만원 ÷ 4,000만원 = 약 0.6년


★POC : 치명적인 리스크 기능, 고객 핵심가치, 불필요한 기능
① 치명적인 리스크 기능
  - 이미지 구분 기능 : 체결(적정 스펙의 부품, 목표 체결부), 용접(용접 간극, 작업 전/후 이미지)
  - 좌표 환산 기능 : 로봇팔 이동중 거리변화, 목표 작업부위 위치 산출
② 고객 핵심가치
  - 체결·용접 완료 후, 이미지 기반의 작업 품질 판단 기능
    *체결작업 : 볼팅 및 배관 체결력 부족, 전력/통신 케이블 접속 불량
    *용접작업 : 과용접으로 인한 구조적 강도 저하, 용접 틈 발생으로 가스·용액 Leak 발생
③ 불필요한 기능
  - HMI 제어 파라미터 수정 기능, 로봇 안전거리 인터록 설정
