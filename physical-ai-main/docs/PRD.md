# AI 비전 기반 6축 로봇 좌표 인식·자동보정 시스템 PRD

## 1. 문제 정의 (Problem Statement)

**현재 문제**
자동차 부품, 전자·배터리 조립 라인에서 6축 로봇은 사전에 티칭(Teaching)된 고정 좌표를 기준으로 체결(스크류/너트러너) 및 용접(스폿/아크) 작업을 수행한다. 그러나 실제 현장에서는 다음 요인으로 부품의 실제 위치가 티칭 좌표와 지속적으로 어긋난다.
- 지그(Fixture) 클램프 반복 사용에 따른 마모·백래시 (누적 공차 연 ±0.3~1.0mm 수준)(가정)
- 부품 자체의 사출/프레스 공차 (로트별 편차 ±0.2~0.5mm)(가정)
- 컨베이어 반복 정지 위치 편차 (±0.5~1.5mm)(가정)
- 설비 열팽창에 의한 미세 좌표 드리프트

이러한 편차가 로봇 작업 허용 공차(통상 체결 ±0.3mm, 용접 ±0.5mm)를 초과하면 나사 헛돌음, 체결 토크 불량, 용접 비드 이탈, 파지 실패 등의 불량으로 이어진다.

**기존 방식의 한계**
- 고정 지그 + 고정 티칭 방식은 지그·부품의 시간에 따른 변화를 반영하지 못한다.
- 편차 발생 시 라인을 정지하고 작업자가 육안·수동 게이지로 확인 후 티칭 좌표를 재입력해야 하며, 1회 평균 2~4시간이 소요되고 숙련자가 필요하다.
- 룰 기반(임계값·템플릿 매칭) 비전 검사는 조명 변화, 반사, 표면 오염, 부품 형상 변경 시 검출 실패율이 급증한다.
- 사람에 의한 수동 보정은 작업자별 정밀도 편차가 크고 재현성이 낮다.

**핵심 가치**
카메라 비전으로 체결부·용접부의 실제 좌표(X, Y, θ)를 매 사이클마다 검출해 기준 좌표와의 편차를 실시간 계산하고, 로봇 작업 좌표를 자동 오프셋 보정함으로써 **재티칭 없이 위치 편차를 상시 자동 보정**한다. 불량률 감소, 라인 정지시간 감소, 숙련 작업자 의존도 감소가 목표다.

**왜 AI가 필요한가**
체결부·용접부 중심점과 회전각도 검출은 부품 로트 편차, 표면 반사, 조명 변화, 미세 오염 등 비정형 조건에서도 서브밀리미터 수준 정확도를 유지해야 한다. 딥러닝 기반 키포인트 검출(Keypoint Detection) 모델은 이런 조건 변화에 강인하여, 룰 기반 대비 검출 성공률과 정밀도를 동시에 확보할 수 있다.

## 2. 사용자 시나리오 (User Scenario)

**1단계 – 설치 및 초기 캘리브레이션**
설비 엔지니어가 로봇 손목 또는 작업 스테이션 상단에 카메라·조명을 설치하고, 로봇 좌표계와 카메라 좌표계 간 핸드아이 캘리브레이션(Hand-Eye Calibration)을 수행한다. 기준 부품(Master Part)을 다수 촬영해 체결부/용접부 기준 좌표(X₀, Y₀, θ₀)와 허용 공차(체결 ±0.3mm/±0.5°, 용접 ±0.5mm/±1.0°)(가정)를 등록한다.

**2단계 – 데이터 수집**
PLC가 컨베이어/지그 정지 완료 신호를 받으면 카메라 트리거 신호를 발생시키고, 카메라가 체결부·용접부를 촬영한다. Edge AI 박스가 이미지를 수신해 전처리(왜곡 보정, ROI 크롭)한다.

**3단계 – 분석 수행**
Edge AI가 키포인트 검출 모델을 구동해 체결부·용접부의 중심 좌표(X, Y)와 회전각도(θ)를 픽셀 좌표에서 실측 좌표(mm)로 변환(캘리브레이션 매트릭스 적용)하고, 기준 좌표 대비 편차(ΔX, ΔY, Δθ)를 계산한다.

**4단계 – 판단 결과 생성**
- 편차가 허용 공차 이내 → "정상" 판정, 보정값 0 적용
- 허용 공차 초과 & 로봇 보정 한계(±3mm, ±5°)(가정) 이내 → "보정 필요" 판정, 오프셋 값 산출
- 보정 한계 초과 → "이상" 판정, 보정 미실행

**5단계 – 제어 실행**
산출된 오프셋(ΔX, ΔY, Δθ)을 로봇 컨트롤러에 실시간 전송(좌표계 오프셋 방식)해 보정된 위치에서 체결·용접 동작을 수행한다. 동작 완료 후 동일 지점을 재촬영해 최종 위치가 허용오차 이내인지 재검증한다.

**6단계 – 결과 확인 및 후속 행동**
재검증 통과 시 "작업 완료" 신호를 PLC에 전달해 다음 공정으로 자동 진행한다. 재검증 실패가 연속 2회 발생하거나 편차가 보정 한계를 초과하면 로봇 인터록이 작동해 스테이션이 정지되고, 대시보드·안돈(Andon)에 위치 이상 알람이 표시되어 작업자가 현장을 확인하고 원인(지그 마모, 부품 불량 등)을 조치한다.

## 3. 성공 지표 (Success Metrics)

| KPI | 목표 수치 |
|---|---|
| 좌표 검출 정확도 (X/Y) | ±0.15mm 이내 (2σ 기준) |
| 회전각도 검출 정확도 (θ) | ±0.3° 이내 |
| 자동보정 성공률 (허용공차 내 진입) | 99.0% 이상 |
| 검출→보정값 산출 사이클타임 | 250ms 이하 |
| 1회 보정 후 재검증 통과율 | 98% 이상 |
| 오검출로 인한 오보정률 (False Correction Rate) | 0.1% 이하 |
| 시스템 가동률 (Uptime) | 99.5% 이상 |
| 라인 다운타임(재티칭 기인) 감소율 | 기존 대비 40% 이상 (가정) |
| 인터록 알람 오탐률 (False Alarm Rate) | 1% 이하 |
| 카메라 캘리브레이션 재점검 주기 | 3개월 (가정) |

## 4. 기술 스택 (Technology Stack)

| 구성 | 사용 기술 | 선정 이유 |
|---|---|---|
| 카메라 | Basler ace2 GigE (500만 화소급, 글로벌 셔터) | 고속 트리거 촬영, GenICam 표준으로 산업 PLC/로봇 연동 용이 |
| 조명 | 동축(Coaxial) LED + 링 조명 | 반사면·미세 형상에서도 안정적 대비(Contrast) 확보로 검출 정확도 향상 |
| 센서 | 포토센서/근접센서(트리거) + 로봇 엔코더 피드백 | 정확한 촬영 타이밍 확보 및 로봇 실좌표 크로스체크 |
| MCU/PLC | Siemens S7-1500 또는 Beckhoff CX 시리즈 | 카메라 트리거, 인터록, 안전 신호 처리를 위한 산업 표준 제어기 |
| Edge AI | NVIDIA Jetson Orin NX 16GB (IP54 산업용 인클로저) | 온디바이스 추론으로 250ms 이하 저지연 확보, 네트워크 단절 시에도 독립 동작 |
| AI 모델 | 경량 CNN 기반 Keypoint Detection (YOLOv8-Pose 커스텀 파인튜닝) + 좌표 회귀 헤드 | 중심점·회전각도 동시 검출에 최적화, 엣지 실시간 구동 가능한 경량 구조 |
| 로봇 컨트롤러 | Fanuc R-30iB Plus / KUKA KR C5 / 현대로보틱스 Hi6 | 실시간 좌표 오프셋 수신 및 서보 제어를 지원하는 산업 표준 컨트롤러 |
| 서버 | On-premise 랙마운트 Edge 서버 (모델 버전관리·로그 집계) | 공장 폐쇄망 내 운영으로 외부 클라우드 의존 최소화, 데이터 반출 리스크 차단 |
| 통신 | EtherNet/IP, PROFINET, EtherCAT(로봇·PLC 연동), MQTT(알람·대시보드) | 산업 현장 표준 실시간 통신, 낮은 지터로 좌표 오프셋 전송 안정성 확보 |
| 데이터베이스 | PostgreSQL + TimescaleDB | 시계열 좌표·편차·보정 이력 저장 및 통계/추이 분석에 최적화 |
| 대시보드 | Grafana + React 기반 자체 웹 대시보드 | 실시간 편차 추이, 보정 성공률, 알람 이력 모니터링 |
| 알림 시스템 | Andon 신호탑 + PLC 알람 + Slack/Teams Webhook | 현장 즉시 인지(신호탑)와 관리자 원격 인지(메신저)를 이중화 |

## 5. 개발 범위 / 비범위 (Scope)

**개발 범위 (In Scope)**
1. 카메라 이미지 기반 체결부/용접부 중심 좌표(X, Y) 및 회전각도(θ) 실시간 검출
2. 기준 좌표 대비 편차(ΔX, ΔY, Δθ) 계산 로직
3. 로봇 컨트롤러 대상 좌표 오프셋 자동 전송(자동보정) 기능
4. 보정 동작 후 재촬영 기반 허용오차 충족 여부 재검증
5. 보정 한계 초과 또는 반복 보정 실패 시 인터록 및 위치 이상 알람 발생
6. 검출·편차·보정·재검증 전 과정 이력 데이터 저장(로그)
7. 실시간 모니터링 대시보드(편차 추이, 보정 성공률, 알람 이력 시각화)
8. 관리자 페이지(기준 좌표/허용공차 설정, 카메라 캘리브레이션 관리, 모델 버전 관리)

**개발 제외 범위 (Out of Scope)**
1. 음성 인식 및 음성 명령 인터페이스
2. 모바일 전용 애플리케이션 개발
3. 다국어 UI 지원 (1차 버전은 국문 기준)
4. 클라우드 기반 실시간 모델 재학습 파이프라인 (1차 버전은 온프레미스 수동 재학습)
5. 다중 사용자 권한 관리 (Role-based Access Control)
6. 로봇 경로 계획(Path Planning) 및 충돌 회피 알고리즘
7. 도장·외관 스크래치 등 품질 외관 검사 기능

## 6. ROI 분석 (Business Value)

가정 전제(가정): 3교대(24시간) 운영되는 자동차 부품 조립·용접 라인 내 로봇 셀 1식(로봇 1대 + 비전 보정 시스템 1식) 기준.

| 항목 | 금액(원) |
|---|---|
| 초기 투자비 (CAPEX) | 90,000,000 |
| 월 절감액 (Gross Benefit) | 13,500,000 |
| 월 운영비 (OPEX) | 2,100,000 |
| 월 순 절감액 (Net Benefit) | 11,400,000 |
| 연간 순 절감액 | 136,800,000 |
| 연간 ROI (%) | 152.0% |
| 투자 회수기간 (Payback Period) | 약 7.9개월 |

- **CAPEX 세부 내역(가정)**: 하드웨어(카메라·조명·Edge AI 박스·로봇 통신 모듈) 65,000,000원 + AI 모델 초기 개발비(데이터 수집·라벨링·학습·검증) 20,000,000원 + 설치·시운전·캘리브레이션 5,000,000원
- **월 절감액 세부 내역(가정)**: 재티칭 인건비 절감 6,000,000원 + 다운타임 감소에 따른 생산 손실 회피 5,000,000원 + 불량/재작업·클레임 비용 절감 2,500,000원
- **월 운영비 세부 내역(가정)**: Edge AI 전력비 300,000원 + 유지보수(카메라·조명 점검) 1,000,000원 + 모델 재학습 공수 800,000원

**최종 판정 결과: 투자 적합 (Go)**

투자 회수기간이 8개월 이내이고 연간 ROI가 150%를 상회해 재무적 타당성이 매우 높다. 재티칭 인건비와 불량 재작업 비용이 명확히 절감되는 고빈도 편차 발생 라인에 우선 적용을 권장하며, 1개 로봇 셀 검증 후 동일 라인 내 타 로봇 셀로 확대 적용 시 AI 모델 개발비가 재사용되어 추가 투자 대비 ROI가 더욱 개선될 것으로 예상된다.
